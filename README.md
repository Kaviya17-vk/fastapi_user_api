# User Management REST API

A basic User Management API built with FastAPI, Pydantic, SQLAlchemy, and SQLite.

## How to Run the Project

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the server:
   ```bash
   uvicorn main:app --reload
   ```

3. Open Swagger UI documentation:
   Go to [http://127.0.0](http://127.0.0) in your browser.
